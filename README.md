# Cruzadinha de Arquitetura Computacional

Jogo de palavras-cruzadas para treinar os termos da disciplina de Arquitetura Computacional.

## Como jogar

1. Leia as pistas nas listas de **Horizontais** e **Verticais**.
2. Clique em uma casa do tabuleiro e digite as letras.
3. Use as setas do teclado, Tab ou clique para navegar entre as casas.
4. Quando todas as casas estiverem preenchidas, clique em **Conferir** para ver quais palavras estão certas.
5. O contador mostra quantas palavras você acertou.
6. Clique em **Reiniciar** para limpar o tabuleiro e começar de novo.

## Palavras e pistas

### Horizontais

| Nº | Palavra | Pista |
|---|---|---|
| 4 | DMA | Técnica que permite transferir dados sem a intervenção constante do processador. |
| 9 | MICROCONTROLADOR | Chip que integra processador, memória e periféricos em um só. |
| 11 | DUALCORE | Processador com dois núcleos de processamento. |
| 12 | CACHE | Memória rápida que guarda dados usados com frequência. |
| 13 | RAM | Memória volátil usada para armazenar dados temporários. |
| 14 | QUADCORE | Processador com quatro núcleos de processamento. |

### Verticais

| Nº | Palavra | Pista |
|---|---|---|
| 1 | EEPROM | Memória não volátil que pode ser apagada e regravada eletricamente. |
| 2 | CPU | Componente que executa instruções e coordena o sistema. |
| 3 | ULA | Parte da CPU que faz as contas e as operações lógicas. |
| 4 | DATABUS | Conjunto de fios que transporta informações entre componentes. |
| 5 | FLASH | Memória não volátil usada em pendrives e cartões. |
| 6 | UC | Parte da CPU que coordena e controla as operações. |
| 7 | ROM | Memória que só permite leitura e guarda dados permanentes. |
| 8 | ADDRESSBUS | Conjunto de fios que indica onde o dado está na memória. |
| 9 | MEMORIADEMASSA | Armazenamento permanente de grande capacidade, como HD e SSD. |
| 10 | REGISTRADORES | Pequenas memórias rápidas dentro do processador. |
